# UI Brief

Kamu sebagai UI/UX Designer yang berpengalaman dalam membuat desain aplikasi website
Style:
- Modern, clean, professional
- Inspirasi: SaaS dashboard, asset management
- Layout responsive desktop dan mobile
- Gunakan card, sidebar, table, badge status, filter, search
- Jangan pakai UI polos
- Gunakan Tailwind CSS
- Gunakan komponen reusable


Komponen:
- Sidebar
- Header
- StatCard
- DataTable
- SearchFilter
- StatusBadge
- MapPlaceholder
